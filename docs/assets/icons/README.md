# Icon Sources

All 18 icons are stored locally as 48px SVG tiles. The root README links each logo to its project's official website; Bash is intentionally unlinked. No remote icon-generation service is needed to render the README.

| Local files | Source | License |
| --- | --- | --- |
| `python.svg`, `fastapi.svg`, `sklearn.svg`, `postgres.svg`, `docker.svg`, `kubernetes.svg`, `githubactions.svg`, `prometheus.svg`, `grafana.svg`, `bash.svg` | [Skill Icons](https://github.com/tandpfun/skill-icons), downloaded individually from `https://skillicons.dev/icons?i=<id>&theme=dark` | [MIT, local copy](skill-icons-license.txt) |
| `mlflow.svg`, `airflow.svg`, `helm.svg`, `pytest.svg` | [Go Skill Icons](https://github.com/LelouchFR/skill-icons), downloaded individually from `https://go-skill-icons.vercel.app/api/icons?i=<id>&theme=dark` | [MIT, local copy](go-skill-icons-license.txt) |
| `dvc.svg`, `uv.svg`, `ruff.svg`, `traefikproxy.svg` | [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons), paths from the matching `<id>.svg` files | [Simple Icons license](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md) |

The Simple Icons logos have local dark-background wrappers. Other tiles retain their source artwork. Logos remain the property of their respective owners; collection licenses do not grant trademark rights.
